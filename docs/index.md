# What was, what is, what then, do

![witdo: mountains at dusk, a river running towards the sun](assets/banner.webp)

witdo is a calm, private, local-first task manager, as a desktop app or in the
terminal. Your tasks are plain Markdown files in a folder you choose, pleasant
to read and edit in Obsidian or any text editor. There is no account, server,
telemetry or network access.

[Get started](getting-started.md){ .md-button .md-button--primary }
[Task file format](task-file-format.md){ .md-button }

!!! warning "Early development"
    The desktop window and the terminal app open, but witdo does not manage
    tasks yet. Pages in this guide describe how it will work, and say so where
    a feature is not built yet.

## What it does

- :material-inbox-arrow-down: Capture tasks quickly into an inbox.
- :material-file-tree: Organise them into tasks and subtasks, and say which
  tasks must be done before others.
- :material-arrow-right-circle: See what to do **next**: open tasks that
  nothing is blocking.
- :material-tag-multiple: Give tasks a priority, a due date, a category, tags
  and notes; search and filter them.
- :material-account-switch: Keep personal and work tasks apart, in separate
  profiles and workspaces that never mix.
- :material-language-markdown: Keep everything in plain Markdown files, which
  you can read, edit, back up and sync with any tool.
